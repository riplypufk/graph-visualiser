# Инструмент визуализации графа зависимостей для менеджера пакетов

## Этап 2 — получение прямых зависимостей пакета

На втором этапе реализовано получение информации о пакете в формате **Alpine Linux (apk)** и извлечение его прямых зависимостей из интернет-репозитория Alpine Linux.

### Реализовано

- получение URL репозитория из `config.yaml`;
- загрузка файла `APKINDEX.tar.gz` из репозитория Alpine Linux;
- распаковка и анализ `APKINDEX`;
- поиск пакета по имени и точной версии;
- извлечение прямых зависимостей из поля `D:`;
- вывод найденных зависимостей в консоль;
- обработка ошибок при загрузке репозитория и поиске пакета;
- автоматическое тестирование реализованной функциональности.

Для получения зависимостей **не используются менеджеры пакетов или сторонние библиотеки**. Используются стандартные библиотеки Python.

## Конфигурация

Параметры программы задаются в файле `config.yaml`.

Пример конфигурации:

```yaml
package_name: curl
repository: https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64
test_repository_mode: false
package_version: "8.14.1-r2"
graph_image_file: dependencies.png
ascii_tree: true
```

Основные параметры:

| Параметр | Назначение |
|---|---|
| `package_name` | Имя пакета |
| `repository` | URL репозитория Alpine Linux |
| `test_repository_mode` | Режим тестового репозитория |
| `package_version` | Требуемая версия пакета |
| `graph_image_file` | Имя файла изображения графа |
| `ascii_tree` | Вывод ASCII-дерева |

Для получения реальных зависимостей из интернет-репозитория параметр `test_repository_mode` должен иметь значение `false`.

## Запуск

Для запуска проекта используется скрипт `run.sh`.

```bash
./run.sh
```

Скрипт выполняет два последовательных действия:

1. запускает автоматические тесты;
2. если все тесты успешно пройдены, запускает основную программу.

Используемые команды:

```bash
python3.10 -m unittest discover -s tests -v
```

и:

```bash
python3.10 -m src.main --config config.yaml
```

Если хотя бы один тест завершится с ошибкой, запуск основной программы не выполняется.

## Результат работы

При успешном запуске программа выводит параметры конфигурации и найденные прямые зависимости.

Пример:

```text
=== Запуск тестов ===
...
----------------------------------------------------------------------

OK

=== Запуск программы ===
Параметры конфигурации:
package_name: curl
repository: https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64
test_repository_mode: false
package_version: 8.14.1-r2
graph_image_file: dependencies.png
ascii_tree: true

Прямые зависимости:
libcurl=8.14.1-r2
so:libc.musl-x86_64.so.1
so:libcurl.so.4
so:libz.so.1
```

В результате программа получает из репозитория Alpine Linux информацию о выбранном пакете и выводит его **прямые зависимости**.

На данном этапе зависимости второго уровня не анализируются и граф зависимостей ещё не строится.

## Тестирование

Для этапа 2 реализованы автоматические тесты, проверяющие:

- разбор зависимостей;
- обработку пустого списка зависимостей;
- разбор `APKINDEX`;
- извлечение `APKINDEX` из архива;
- поиск пакета;
- проверку версии пакета;
- обработку неизвестного пакета;
- корректность конфигурации.

Всего выполняется **17 тестов**.

Проверка выполняется автоматически при запуске:

```bash
./run.sh
```

Успешный результат:

```text
Ran 17 tests in 0.002s

OK
```

```text
graph visualiser/
```

### Основные файлы

- `src/main.py` — загрузка конфигурации, её проверка и запуск программы;
- `src/dependencies.py` — получение и обработка `APKINDEX`, поиск пакета и извлечение зависимостей;
- `tests/test_config.py` — тесты конфигурации;
- `tests/test_dependencies.py` — тесты работы с `APKINDEX` и зависимостями;
- `config.yaml` — конфигурация программы;
- `run.sh` — автоматический запуск тестов и программы;
- `README.md` — документация проекта.

## Результат этапа 2

На втором этапе реализовано получение прямых зависимостей указанного пакета Alpine Linux из интернет-репозитория.

Программа успешно находит пакет по имени и версии, извлекает его прямые зависимости из `APKINDEX` и выводит их в консоль.
